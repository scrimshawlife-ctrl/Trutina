## I. Assay, not minds
Outputs are score packets. No phenomenal head. No forecast mint. Trutina weighs a settled pair. It does not call the future.

## II. Function first, weights second
T0 is `BRIER_BINARY_V1` = (p − y)² on operator-settled (p, y). A trained head exists only after labeled settled pairs + operator sentence + beat T0 on held-out pairs.

## III. Submodule default
Trutina-the-model is not a new Tier-1. It binds `yggdrasil.replay` as home. Specialist id on Spec 009 stays `abx.brier`. Function slice is `trutina.score`. Standalone promotion needs Research Shadow Replay.

## IV. Packet in, packet out
Product surface is `brier.score.v0`. No chat template. No hard import of Abraxas-v2.0.

## V. Split is frozen
Owns: SCORE, BATCH, DECOMPOSE, and advisory stubs FUSION_ADVISORY / ROUTER_MICRO / GATE_ADVISORY / PROJECT.
Does not own: form/lexical (Hyperlex); family/wave/correspondence (Athanor); triad/sign_class (Semion); route_class (Yggdrasil); forecast mint (PSE); promotion law (governance); ledger finalization ids (canon ledger).

## VII. Name-gate
Allow: `trutina-score-*`, `trutina-ledger-*`, `trutina-surface-*`, `abx-brier-ledger-*`, `abx-brier-surface-*`
Deny: `trutina-chat-*`, `trutina-mind-*`, `trutina-forecast-*`, `trutina-dpo-*`, person-name checkpoints.

## VIII. Human sovereignty
T1 train, Hub upload, gold-settle, Spec 009 router bind, constitution amendment, ledger id finalization, and any claim that this repo replaces `outcome_brier` require an operator sentence.

## IX. Dual-use bound
Detector over generator. Scores measure calibration. They do not mint edges for wagering products. HollerSports remains informational.

## X. One conceptual change per cycle
Do not open a new mode in the same cycle as packet-schema changes.
